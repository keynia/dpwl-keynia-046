# Pertemuan
1. kesinambungan PWD–DPW–DPWL;
Jawaban:1. Kesinambungan PWD–DPW–DPWL
-PWD (Perancangan Web Dasar): mempelajari dasar pembuatan halaman web seperti HTML, CSS, dan konsep dasar PHP.
-DPW (Desain dan Pemrograman Web): mengembangkan web menjadi aplikasi yang lebih interaktif dengan PHP, database, dan pengolahan data.
-DPWL (Desain Pemrograman Web Lanjutan): mengembangkan aplikasi lebih terstruktur dan kompleks, misalnya menggunakan MVC, framework, dan keamanan aplikasi.
2. perbedaan PHP terstruktur dan MVC;
Jawaban:PHP terstruktur: kode program, tampilan, dan proses pengolahan data sering berada dalam satu atau beberapa file yang saling bercampur.
MVC: program dipisahkan menjadi Model, View, dan Controller sehingga kode lebih terorganisir, mudah dikembangkan, dan dipelihara.
3. fungsi Model, View, dan Controller;
Jawaban:-Model: mengelola data dan komunikasi dengan database.
-View: menampilkan antarmuka atau hasil kepada pengguna.
-Controller: menerima request pengguna, mengatur proses, dan menghubungkan Model dengan View.
4. alur request–response MVC;
Jawaban:User → Request → Controller → Model → Controller → View → Response → User
5. pemetaan satu atau beberapa bagian/fitur aplikasi DPW ke Model, Controller, dan View disertai alasan; dan
Jawaban:Contoh fitur Data Mahasiswa:
-Model: Mahasiswa → mengatur data mahasiswa dan proses database.
-Controller: MahasiswaController → menangani tambah, ubah, hapus, dan tampil data mahasiswa.
-View: mahasiswa.php → menampilkan tabel dan form data mahasiswa.
6. kesimpulan P1.
Jawaban:P1 ini menunjukkan perkembangan dari pemrograman web dasar menuju aplikasi web yang lebih terstruktur. MVC memisahkan data, proses, dan tampilan sehingga aplikasi DPW lebih rapi, mudah dipelihara, dan mudah dikembangkan.
